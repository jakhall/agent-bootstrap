# Installing agent-bootstrap globally for Claude Code (Windows)

An agent asked to "install agent-bootstrap" on a new machine follows these steps in order and finishes with the report in step 4. For adding the workflow to a single repository instead, see README.md ("How To Adopt It").

## 1. Check tools

- `git`, `node` (any current LTS) and Windows PowerShell 5.1 (`powershell`). The hooks run on Node; the sync script runs on PowerShell. Missing either: stop and tell the user.

## 2. Clone to the fixed path

The sync script and the hooks expect the clone at exactly `~/.claude/agent-bootstrap`:

```bash
git clone https://github.com/jakhall/agent-bootstrap.git "$HOME/.claude/agent-bootstrap"
```

If it already exists, `git -C "$HOME/.claude/agent-bootstrap" pull --ff-only` instead.

## 3. Run the installer

```bash
node "$HOME/.claude/agent-bootstrap/.agents/tools/install-global.mjs"
```

It is idempotent and writes only:

| Target under `~/.claude/` | What |
|---|---|
| `CLAUDE.md` | A managed block between `agent-bootstrap:begin/end` markers: the import of `.agents/AGENTS.md`, global path rules, and memory-scope rules. Text outside the markers is kept. Source: `.agents/tools/global/CLAUDE.md`. |
| `settings.json` | `SessionStart` (inject `discovery.md`, warn on wrapper drift) and `PostToolUse` `Write\|Edit` (advisory checks) hooks, and `outputStyle: "Scannable"` when no style is set. Other keys are kept; the previous file is saved as `settings.json.bak-agent-bootstrap`. |
| `output-styles/scannable.md` | The "Scannable" reply style. |
| `agent-bootstrap-sync.ps1` | The update shim. |
| `skills/ab-*` | One full-text wrapper per skill, generated by the sync script. |

If it reports `skip CLAUDE.md`, the file already imports the workflow outside the markers: show the user, remove that copy with their agreement, and re-run. Then run `node "$HOME/.claude/agent-bootstrap/.agents/tools/install-global.mjs" --check`; it must exit 0.

## 4. Report back

State the installer's per-target lines, the `--check` result, the number of `ab-*` skills, and anything skipped. Tell the user to restart Claude Code.

## Updating

```bash
powershell -NoProfile -File "$HOME\.claude\agent-bootstrap-sync.ps1"
```

This pulls the clone and regenerates the `ab-*` wrappers. Re-run the installer only when `--check` reports drift (a template under `.agents/tools/global/` changed).

## Context cost

Kept deliberately small: one `CLAUDE.md` block plus `.agents/AGENTS.md` (always loaded), the `ab-*` skill descriptions (model-invoked ones only), the output style, and `discovery.md` per repo at session start. Skill bodies, standards and project notes load only when used. The memory-scope rules keep each repo's memories out of the global index.
